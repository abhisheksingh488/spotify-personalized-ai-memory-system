\# Data Assets



This directory contains versioned schemas, synthetic demo data, and evaluation assets.



\## schemas/



Contains:



\- Interaction event schema

\- Memory schema

\- Embedding metadata schema

\- Policy registry

\- Temporal memory graph schema



\## synthetic/



Contains synthetic demo data for development and testing.



\## evaluation/



Contains golden evaluation cases for:



\- Security

\- Retrieval

\- Privacy

\- Memory lifecycle

\- Provenance

\- Deletion



Synthetic data must not contain real user information.

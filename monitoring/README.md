\# Monitoring



The system should monitor:



\- API availability

\- Request failures

\- Request latency

\- Memory processing

\- Memory retrieval

\- Corrections

\- Deletions

\- Authorization failures

\- Storage health



\## Services



Monitor:



\- Neo4j

\- Qdrant

\- PostgreSQL

\- Redis

\- Kafka/Redpanda



\## Tracing



Trace IDs should connect the memory workflow from retrieval to context composition.



\## Privacy



Monitoring must not expose secrets or sensitive memory contents.
